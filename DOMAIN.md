# AI-first development platform

Платформа связывает сотрудников, проекты, агентов и правила компании. Этот словарь фиксирует язык продукта и процесса разработки платформы. Сценарии MVP определены в `docs/first-version.md`.

## Language

### Продукт

**Компания**:
Арендатор платформы. Объединяет сотрудников, проекты и установку GitHub App.
_Avoid_: организация, tenant, workspace

**Организация GitHub**:
Внешняя организация GitHub, где установлен GitHub App.
_Avoid_: компания

**Команда GitHub**:
Внешняя команда организации GitHub. Соответствует проекту.
_Avoid_: группа, команда проекта

**Сотрудник**:
Учётная запись человека в одной компании. Имеет сессии и токены агента.
_Avoid_: пользователь, аккаунт

**GitHub username**:
Имя учётной записи GitHub сотрудника. Платформа использует его для команд GitHub.
_Avoid_: логин GitHub, ник

**Приглашение**:
Ссылка с ограниченным сроком. По ней человек создаёт учётную запись сотрудника в компании.
_Avoid_: инвайт, заявка

**Проект**:
Единица работы компании. Объединяет сервисы, участников и одну инструкцию.
_Avoid_: workspace, репозиторий

**Сервис**:
Часть проекта с ровно одним GitHub-репозиторием.
_Avoid_: приложение, компонент

**Репозиторий**:
GitHub-репозиторий, привязанный к сервису.
_Avoid_: репа, проект

**Инструкция**:
Текст с командами установки и правилами работы агента. Одна на проект.
_Avoid_: README, гайд

**Участник проекта**:
Сотрудник, добавленный в проект. Все участники равны.
_Avoid_: член, владелец, пользователь проекта

**Агент**:
Внешний инструмент сотрудника. Подключается к платформе по личному токену и действует от имени сотрудника.
_Avoid_: бот, ассистент

**Токен агента**:
Личный токен сотрудника для подключения агента. Даёт только права сотрудника.
_Avoid_: API-ключ, пароль агента

**Деактивация**:
Закрытие входа сотрудника, удаление из проектов и команд GitHub, отзыв токенов агента.
_Avoid_: увольнение, блокировка

**Синхронизация доступа**:
Приведение участников проекта и команд GitHub к одному составу.
_Avoid_: провижининг, sync

### Процесс разработки

**Полный путь**:
Последовательность от спецификации до закрытия задачи: реализация, проверки, коммит, независимое ревью, исправления, PR, принятие, merge, закрытие задачи.
_Avoid_: пайплайн, workflow

**Задача**:
GitHub issue, единица работы и учёта в трекере.
_Avoid_: тикет, таск

**Спецификация**:
Согласованное описание результата и критериев приёмки. Живёт в теле задачи или в связанном документе.
_Avoid_: ТЗ, описание задачи

**Изменение**:
Коммиты в ветке задачи, которые реализуют спецификацию.
_Avoid_: правка, дифф

**Ревью**:
Независимая проверка изменения против стандартов проекта и спецификации.
_Avoid_: проверка кода, ревью PR

**Принятие**:
Явное одобрение результата человеком. Без принятия нет слияния.
_Avoid_: аппрув, акцепт

**Правила проекта**:
Записанные требования к веткам, проверкам, pull request и слиянию.
_Avoid_: регламент, процесс

**Доступная проверка**:
Проверка, объявленная в репозитории или задаче, которую можно запустить сейчас.
_Avoid_: тест как синоним любой проверки

**Подтверждённое замечание**:
Замечание с доказательством: пункт спецификации, стандарт проекта или упавшая проверка.
_Avoid_: правка ревьюера

**Блокирующее замечание**:
Подтверждённое замечание, которое запрещает merge до исправления.
_Avoid_: критичное замечание

### Роли

**Автор**:
Агент, который реализует задачу.
_Avoid_: исполнитель

**Ревьюер**:
Отдельный агент с чистым контекстом, который проверяет изменение.
_Avoid_: проверяющий

**Человек**:
Сотрудник, который принимает результат и одобряет merge.
_Avoid_: пользователь, заказчик
