# Границы модулей и outbox

Нужны ясные границы и автоматическая проверка. Модули: Companies, Identity, Projects, Integrations, Agents, SharedKernel.

Каждый модуль — отдельный проект .NET со своей схемой PostgreSQL и своим `DbContext`. Модули не пишут в таблицы друг друга. Межмодульные побочные действия идут через транзакционный outbox. NetArchTest проверяет запрещённые зависимости в CI.

Причины: границы не разрушаются случайно. Синхронизация с GitHub переживает сбой. Модуль можно вынести в сервис позже.

## Последствия

- Больше проектов и миграций.
- Запросы между модулями идут через контракты.
- Межмодульные побочные действия согласованы в итоге, а не сразу.
- Обработчики событий должны быть идемпотентны.
