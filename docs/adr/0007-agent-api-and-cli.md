# API агента и CLI

Агент подключается по REST API и CLI. Один endpoint `GET /api/agent/v1/bootstrap` с Bearer-токеном. Он только читает и возвращает компанию, проекты, сервисы, репозитории (`fullName`, `sshUrl`, `httpsUrl`), инструкции и GitHub username. Ошибки: `401`, `403`, `404`. Пагинации нет. MCP-адаптер добавим позже.

Причины: CLI конкретен для MVP: он забирает данные, готовит окружение и проверяет доступ. API отделён от web API и версионируется отдельно.

## Рассмотренные варианты

- MCP с первого дня: дополнительная поверхность.
- GraphQL: избыточен для одного клиента.

## Последствия

- API агента только для чтения.
- Web-сессия не может вызывать API агента.
- CLI отвечает за клонирование и проверку доступа.
