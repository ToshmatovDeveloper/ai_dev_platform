# Интеграция с GitHub App

Модуль Access владеет установкой GitHub App. На проект создаётся команда `aidp-<project-slug>`, она получает право `write` на репозитории проекта. Сотрудник указывает GitHub username в профиле. Webhooks в MVP нет; синхронизацию повторяет outbox. Права App: Members read/write, Administration write, Metadata read. `Contents` не нужен.

Причины: команды GitHub проще синхронизировать, чем прямых коллабораторов. Отзыв доступа — удаление из команды. Без webhooks меньше внешних точек отказа.

## Рассмотренные варианты

- Прямые коллабораторы: сложнее синхронизация.
- Личные токены GitHub: небезопасно.
- Webhooks: отложены.

## Последствия

- Установка App — разовая внешняя операция.
- Синхронизация согласована в итоге.
- Ошибки GitHub видны как `failed`.
