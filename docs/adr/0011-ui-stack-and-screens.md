# UI-стек и экраны

Нужен внутренний CRUD-интерфейс для S1–S4 и S6. Панель админа не входит в MVP.

## Решение

Стек:
- React Router.
- TanStack Query.
- React Hook Form и Zod.
- Mantine.
- Типы API генерируются из OpenAPI. CI проверяет расхождение.

Экраны:
- вход;
- принятие приглашения;
- список проектов;
- создание проекта;
- карточка проекта: сервисы, участники, инструкция;
- компания: приглашение и деактивация;
- профиль: GitHub username и токены агента;
- 404 и 403.

Корень `/` ведёт на `/acme/login`.

## Причины

- Mantine быстрее для внутреннего CRUD: формы, модальные окна, уведомления, таблицы.
- Генерация типов из OpenAPI снижает расхождение с backend.
- Список экранов покрывает S1–S4 и S6.

## Последствия

- UI следует контракту `docs/technical-foundation/web-api-contract.md`.
- Дизайн-системы и мобильной версии в MVP нет.
- Тесты компонентов: Vitest и React Testing Library.
- E2E появится позже.
