# Локальное окружение, конфигурация и эксплуатация

В разработке Docker поднимает `db` и `mailhog`, API и Vite запускаются локально. Полный Compose (`db`, `api`, `web`, `mailhog`) — для smoke-проверки. Конфигурация — `appsettings.json` и переменные окружения; секреты не в Git; ключ GitHub App монтируется файлом. Логи — структурный JSON. Деплой — один хост с Docker Compose и Nginx.

Причины: быстрый цикл разработки. Один origin для cookie. Простая эксплуатация для MVP. Метрики, трейсинг, алерты и Kubernetes отложены.

## Рассмотренные варианты

- Kubernetes: больше операций, чем нужно.
- Полный Compose в разработке: медленная перезагрузка.

## Последствия

- `.env.example` в Git, `.env` нет.
- Нужны `/health/live` и `/health/ready`.
- Авто-деплоя в MVP нет.
