# Структура репозитория и версии рантаймов

Монорепозиторий: `apps/api`, `apps/web`, `src/modules`, `src/shared`, `infra`, `docs`. Один `.sln` для .NET и `pnpm` для фронтенда. Версии: .NET 10 LTS, Node.js 24 LTS, PostgreSQL 17. Nx и Turborepo не берём.

Причины: один репозиторий упрощает сквозные изменения. Один .NET-солюшн и один npm-пакет не требуют оркестратора сборки.

## Рассмотренные варианты

- Полирепозиторий: сложнее синхронные изменения.
- Nx или Turborepo: лишний инструмент для одного пакета.

## Последствия

- Версии закреплены в `global.json`, `.nvmrc` и образе Postgres.
- Модуль — отдельный проект .NET с `*.Contracts`.
