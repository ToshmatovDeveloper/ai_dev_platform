# Общая БД и company_id

Компания — арендатор платформы. Решение: одна БД PostgreSQL, много компаний, `company_id` в каждой таблице. Компания — сущность в модуле Employees. Компания определяется по slug в пути, сессия хранит `company_id`.

Причины: добавить `company_id` сейчас дешевле, чем переделывать все таблицы и запросы позже. Уникальные ограничения включают `company_id`.

## Рассмотренные варианты

- Одна компания на установку: проще сейчас, дорого при второй компании.
- Отдельная БД на компанию: сложнее миграции и эксплуатация.

## Последствия

- Каждый запрос фильтрует по `company_id`.
- Уникальные индексы начинаются с `company_id`.
- Внешних ключей между компаниями нет.
